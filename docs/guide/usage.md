# 使用工作台

[English](usage.en.md)

本文面向已经接入设备的拥有者，说明如何在浏览器中使用工作台。接入设备见[接入设备](devices.md)，定时任务见[定时任务](scheduled-tasks.md)。

## 浏览器与界面

### 支持的浏览器

工作台支持桌面 Chrome 和 Android Chrome，最低 Chromium 97。通过 HTTPS 或 `localhost` 访问时，当前版本的 Chrome 可以从菜单把工作台安装为应用，以独立窗口打开；它仍需连接 server，没有离线功能。

### 登录与语言

主机名或协议不同的入口（例如 `http://192.168.1.10:8080` 和 `https://kiteline.example.com`）分别登录；同一主机、同一协议的不同端口共用登录。语言等偏好按入口（含端口）分别保存在浏览器中。退出登录前会确认放弃未保存的文件；退出只结束这个浏览器的登录，终端会话继续运行。忘记密码时见[重置初始化 token 与密码](server.md#重置初始化-token-与密码)。

语言默认跟随浏览器：中文环境显示简体中文，其他显示英文。切换语言不影响打开的文件和终端。

地址栏记录设备、工作区、工具以及打开的文件、仓库和会话，可以前进、后退和收藏。浏览器标签页标题显示当前工作区、工具和设备；工作台、任务、设备及错误页显示相应上下文，便于辨认多个页面。

server 升级后，已打开的页面显示 Web 和 Server 的版本并暂停远程操作；先复制未保存的内容，再点“刷新页面”。

通过左栏底部的设置菜单选择跟随系统、浅色或深色外观；登录页也提供外观入口。默认跟随系统，手动选择保存在当前浏览器，切回跟随系统后恢复自动切换。外观切换保留打开的文件草稿、撤销历史和选区；终端内容始终使用深色配色。

布局按可用窗口宽度切换。宽度至少 960 CSS 像素时，标题行的布局图标表示当前状态，单击依次切换工作页、协同和终端。协同时，左侧位置图标表示终端当前位置，单击按下、右、上、左循环；分隔条可拖动调整比例，左右侧栏可独立收起。窄布局一次只显示工作页或终端，标题行图标表示切换目标。手机导航和文件／Git工具从对应边缘覆盖正文，可用返回按钮、遮罩或Escape关闭；打开具体内容后回到正文。文件搜索位于工具的更多菜单中。

桌面可拖动左右侧栏的内边缘调整宽度，也可用Tab聚焦分隔条后按左右方向键调整，Home／End移到当前允许的最小／最大宽度。折叠侧栏或往返窄布局会保留宽度；右栏宽度按工作区保留。窗口收窄会采用实际受限宽度，再放宽不会恢复原来的较大值。刷新页面后恢复当前窗口宽度对应的默认值。

跨桌面和手机布局时，草稿、活动标签和会话保留，原有位置和比例继续使用。协同布局缩窄时，正文沿最近一次明确选择的文件或终端交接；例如先选文件再向终端输入，缩窄仍显示文件。手机切换正文后回到桌面，原本只显示一种正文的布局会转为协同。

设备名称、工作区、文件和目录、Git 变化条目及工作页标签支持右键菜单，动作对应所指对象。手机可长按对象或使用其更多按钮；设备管理也可从设备详情右上角的更多菜单进入。编辑器和diff正文继续使用原选字与复制交互，终端正文见下文。

### 设置保存在哪里

| 内容                             | 保存位置                   |
| -------------------------------- | -------------------------- |
| 语言、外观、最近工作区、终端字号 | 当前浏览器                 |
| 终端分组和分屏                   | 当前浏览器标签页           |
| 工作页标签、正文模式和协同布局   | 当前页面，按工作区保留     |
| 未保存的修改、提交消息           | 当前页面，刷新或关闭后丢失 |
| 新会话滚屏行数、终端快捷方式     | 设备，所有入口共用         |
| 设备名称                         | server                     |
| 工作区名称和路径                 | 设备                       |

## 设备与工作区

### 设备

绑定新设备见[用网页命令接入](devices.md#用网页命令接入)，版本不匹配时见[升级 agent](devices.md#升级-agent)。

删除设备后，server 删除设备记录、绑定和定时任务摘要，远程访问立即断开。设备上的 agent、终端会话、定时任务和文件都保留，但 agent 无法再连接，重新接入需要再次绑定。删除记录不会[卸载 agent](devices.md#卸载)。

### 工作区

工作区是设备上登记的一个项目目录。在在线设备的“添加工作区”中选择项目目录；路径按解析符号链接后的真实目录登记，重复添加同一目录得到已有的工作区。

点击左侧“设备与工作区”旁的搜索按钮，可按名称或路径筛选已登记工作区，包括没有终端会话的工作区；筛选不区分大小写。筛选临时展开命中的设备，路径命中时显示完整路径；清空后恢复原来的折叠状态。非空筛选只有一个结果时，按Enter打开该工作区。X清空并继续搜索，再点搜索按钮或按Escape会关闭并清空筛选。完整路径也可在对象菜单和设备详情中查看。

主区左缘的按钮展开或收起导航，手机选择目标后返回正文。从侧栏返回工作区会继续本页内上次打开的目标；重复选择当前目标不会增加后退步骤。用键盘激活侧栏的工作台、任务、设备或工作区，或用筛选框Enter打开唯一结果后，焦点进入正文。页首的“跳到正文”也可直接进入正文。

移除工作区只删除登记，目录和文件保留；设备离线或工作区里还有终端会话时无法移除。因终端会话被拒绝后，可点“前往工作区终端”，结束会话后再重试移除。

工作区不是沙箱：终端、文件和 Git 以项目用户的权限工作，能访问该用户能访问的任何路径。

切换工具、工作区或设备时，终端会话继续运行。离开工作区会关闭它的终端画面，回来后重新附着；未保存的修改和 Git 提交消息保留到页面关闭。终端布局在同一标签页刷新或页面回收后恢复，显式 URL 中的会话优先；浏览器重启或关闭标签页后是否保留由浏览器决定。退出登录会清除保存的布局；浏览器存储不可用时不提示，当前页面仍可调整和保留布局。

## 终端

终端会话运行在设备上：关闭页面、断网、退出登录、server 重启或删除设备都不会结束它。会话在 Shell 或快捷命令退出、你结束它、agent 正常停止或设备重启时结束。异常退出后的处理见[清理遗留的终端会话](reference.md#清理遗留的终端会话)。同一会话可以同时在多个浏览器和本机打开，各客户端都能直接输入，同时输入的字符会交错。

终端长时间无响应时，可关闭同一会话中暂时不用的显示后再试。

### 在线报告

程序发送 OSC 9、OSC 777 通知或主动发送 OSC 7501 blocked 报告时，桌面侧栏会在工作区旁显示标记；手机主区左缘的导航入口显示数量，展开后按工作区列出来源，普通布局的终端搜索期间仍可打开；专注时先退出专注再打开。数量按当前保留报告的来源计算，同源报告更新不累加。工作区内，有待处理报告的会话在终端标签和“选择终端会话”的行上带圆点，行内显示摘要；当前会话以外有报告时，选择会话的按钮也带圆点。未打开显示的会话也可以报告。列表显示来源、历史报告类型、正文和 server 接收时间，按本地时区显示，同日为 `HH:mm`，跨日为 `MM-DD HH:mm`；同一终端只保留最近一条，报告不表示程序当前仍在等待。

展开列表不会清除报告。点击来源会返回原会话，桌面会显露其所在分屏；从文件返回、切换或重新选择终端、重新进入页面，以及页面恢复时看到该终端，都会激活它。以 server 处理激活请求为界，清除当时该终端已有的报告并同步其他端，之后收到的新报告保留。会话列表确认来源已不存在时，设备在线后返回不可用页面也会处理该报告。首次列表读取失败时会保留报告；读取错误仍单独显示。持续停留不会自动清除新报告。协同中的终端沿用同一会话选择和激活规则。

待处理报告保存在 server 内存中，页面恢复或重新连接后同步，server 重启后丢失。会话结束仍保留历史，删除设备时移除其报告。激活请求失败或结果未确认时显示错误，报告以同步结果为准。没有发送这些终端事件的程序不会自动出现在列表中。

### 新建会话与快捷方式

新会话在工作区目录启动，继承 agent 的环境变量（agent 作为服务运行时来自服务配置，见[后台运行](devices.md#后台运行)）。Linux 和 macOS 使用项目用户的登录 Shell，Windows 使用 PowerShell，默认选择和配置见 [shell](reference.md#shell)。

未指定名称的普通 Shell 会话使用同工作区首个可用的 Shell、Shell 2、Shell 3 等名称，结束后的名称可以复用。

快捷方式在登录 Shell 中运行一条命令，命令退出时会话结束。新设备预置的 AI CLI 程序需要自行安装。

“关闭显示”只关闭画面，会话继续运行，可从“选择终端会话”重新打开。

桌面各组标签同排显示，点击组内标签选择会话；选择器中的组勾选控制哪些组显示。隐藏组保留会话、分屏结构和比例，选择其成员会重新显示原组。手机一次显示一个终端。跨布局继续当前会话选择，明确关闭至未选择的状态也会继续；原有桌面分组、分屏结构和比例保留。回到桌面时，手机所选会话成为当前会话并显露所在组和分屏，隐藏组也会重新显示。

桌面使用键盘明确选择会话标签或选择器项目后，会在菜单关闭且目标显示就绪时把输入焦点交给该会话。等待期间的后续按键、指针操作或目标变化，以及离开页面，会取消这次焦点请求。

终端标签标记当前会话，各分屏不再重复显示标题栏。右键标签或打开会话选择器中对应行的更多，可重命名、移动、关闭显示或结束该会话。区域更多提供分屏、排列、最大化、搜索、字体及设置；右侧余位显示程序最近发送的标题，刷新页面或在其他设备打开同一会话时也会显示。分屏在窄区域按保存比例保留最小画布，可滚动查看；从标签或选择器选择会话，以及明确排列分屏时，会显露当前分屏，输出不会拉回手动滚动位置。

### 复制与粘贴

向上滚动即可看到保留的历史，新输出不会把你拉回底部。各客户端的滚动和选择互不影响。

- 桌面：拖选文字，程序接管鼠标时（例如 htop）按住 Shift 拖选；用右键菜单复制，macOS 也可用 Cmd-C。粘贴用 Ctrl-V、Ctrl-Shift-V、Cmd-V 或右键菜单。Ctrl-C 发给程序。
- 手机：轻点终端打开输入法。长按文字或空白处打开菜单，在菜单中粘贴；复制前可拖动选区手柄。已有选区时，先关闭选区再轻点终端。粘贴入口在浏览器支持读取剪贴板时显示。

粘贴过大时不发送，提示“粘贴内容超过容量”。程序显示图片或通过 OSC 52 写剪贴板在网页中不起作用。

手机方向键单击移动一步，按住会连续输入，松手、移出按钮或切换终端后停止。SHIFT、CTRL、ALT 点一次只对下一个按键生效，包括长按的第一步，再点取消。网页中的 Ctrl-b 直接发给程序，不是 tmux 前缀。

### 从终端输出打开文件

桌面按住 Ctrl/Cmd 点击路径，在来源工作区的“文件”中打开；手机长按选中完整路径，再点菜单中的“打开文件”。相对路径始终以工作区根目录为基准，不跟随 Shell 的 `cd`、SSH 或容器目录。

支持 `/` 分隔的相对路径、工作区内的 POSIX 绝对路径和本地 `file://` URI。`:行号` 或 `:行号:列号` 只定位行，复用已打开的未保存稿，超出正文时定位到末行。普通路径中的 `..` 不识别。桌面自动识别完整、无空格的 ASCII 路径；手机精确选区可以含空格和中文。无扩展名文件可写 `./README`，Windows 工作区使用 `/` 相对路径，不识别盘符或反斜杠路径。

### 搜索与显示

桌面和手机的终端控制行用一个按钮按“普通→专注→全屏→还原”循环切换。专注隐藏左右侧栏和顶部设备／工作区标题行；还原后导航入口恢复。切换设备、工作区或工具时会退出终端专注和全屏。手机“专注文件”使用同一规则。

退出全屏后恢复普通布局。终端区域菜单和终端页的设置菜单不再重复专注／全屏动作；其他页面的设置菜单与手机文件更多仍提供全屏。其他页面设置中的独立桌面全屏在切换设备、工作区或离开工作区时退出，同工作区内切换工具时保留。

终端搜索在当前画面已加载的内容（含历史）中查找，不区分大小写。桌面与手机均从终端区域更多选择“搜索终端”，同时显露当前分屏；搜索栏显示目标会话名称，窄区域内控件会换行。搜索期间隐藏当前终端的辅助键，关闭后恢复并可继续输入；已结束会话仍可浏览历史。实际行列数变化后保留搜索文字，但清除搜索结果提示；按 Enter 可重新搜索。

“终端设置”中的“新会话滚屏行数”决定会话保留多少行历史（范围见[限额](reference.md#限额)），只对之后新建的会话生效。

一个会话只有一组行列，由最近输入或调整窗口的客户端决定，其他客户端随之重排；手机打开输入法不改变尺寸。实际行列数变化会清除各显示的选区，并继续显示原来正在阅读的内容；接近底部时按可滚动范围调整，原阅读内容被历史淘汰时显示最早保留内容。

### 连接与恢复

打开会话后，画面和历史恢复完成才能输入。出现问题时：

- 显示“连接已断开”：点“重新连接”。等待或失败时，已有画面保留为只读，仍可滚动、选择和复制；新画面恢复完成后才替换它。某个显示长期跟不上输出时也会单独断开，会话和其他显示不受影响。
- 显示“会话已不存在”：断开期间会话已经结束，例如 agent 或设备重启。显示保留断开前的画面并变为只读，不能重新连接，用“关闭显示”关闭。
- 记录不可用：点“恢复终端”。它为同一个程序重建记录，不重启程序，此前的网页历史不再保留。
- 恢复历史时容量不足或超时：点“减少历史后重试”，只恢复当前画面；设备上的历史不变。
- 连接正常但画面错乱：用终端区域更多的“重绘程序”。它临时改变一次尺寸让程序重绘，其他客户端的画面和选区也可能变化，所以要先确认。仍不正常时“关闭显示”后重新打开。

“历史存在缺口”表示记录器故障期间的部分输出没有进入网页历史。会话结束后画面只读，并显示退出码。

会话菜单的“结束会话”确认一次后，结束会话及其中的全部程序。

### 在 CLI 中接续

会话菜单的“在 CLI 中接续”提供当前设备、工作区和会话的完整命令，在已登录此 server 的本机终端中执行。尚未配置 CLI 时，点“安装与登录”进入引导；设置菜单也提供“CLI 接入”。CLI 与网页操作同一个 Shell，脱离后会话继续运行；按键、安装和凭据见[远程 CLI](cli.md#接续已有终端)。设备本机的工作区与会话管理命令见[命令参考](reference.md#kiteline-agent-命令)。

## 文件

右侧文件工具浏览当前工作区，打开的文件在中间工作页显示，列表路径相对于工作区目录显示。单击文件或 Git 条目后，工作页保留到主动关闭；切到已经打开的页不会复制标签。详情中的“复制设备绝对路径”复制设备上的路径文本；用于 shell 命令时需按 shell 规则引用。

工作页标签只显示文件名。同名文件或同文件不同来源的diff，请打开后按正文路径与比较来源辨认；也可从标签菜单查看完整路径和来源。手机文本文件的正文路径可换行显示。

### 浏览

文件名不是合法 UTF-8 的项，以及 FIFO、socket 和设备节点，请在终端处理。工作台不支持的 Windows 重解析点仍会列出，标记为“类型不支持”且不可操作。

文件被其他程序改动后列表自动刷新，页面可见时也定时刷新。刷新时，当前文件没有未保存内容便采用磁盘版；有未保存内容时保留草稿并提示磁盘已变化。采用不同正文后，原来的撤销和重做历史会清空。设备无法监听目录变化时显示“自动更新受限”，列表仍会定时刷新。

### 打开与编辑

PNG、JPEG、GIF、WebP 图片按内容识别并预览，超过预览大小或像素数时只能下载。其他文件按 UTF-8 文本打开；包含 NUL 字节、不是合法 UTF-8 或超过编辑容量（见[限额](reference.md#限额)）的文件只能下载，不能编辑。

文件编辑器和 Git diff 按文件名显示语法高亮。Diff 只包含部分上下文，跨行注释或字符串可能误着色；以原文为准。

文件工具栏保留引用、保存及内容预览；“更多文件操作”包含查找 / 替换、复制全文、打开所在目录、下载、核对磁盘内容和另存为。“打开所在目录”按当前文件路径定位目录并显示所指文件，未命名稿需先保存。手机还保留专注文件的直达入口。

编辑源码时，从更多菜单选择“查找 / 替换”可搜索当前稿件，包括未保存的修改。替换只修改草稿，保存后才写入磁盘。

文件源码工具栏中的“复制代码行引用”复制选区触及的整行，未选择时复制光标行，并附设备、工作区、相对路径和行号。引用来自当前编辑器正文，包含尚未保存的修改；复制不改变选区或保存文件。再到目标终端手动粘贴即可。

编辑器保留原有的 BOM、换行符和末尾换行；混用换行时会提示保存采用 LF 还是 CRLF。一次修改会让内容超过编辑容量时整体不生效。

Windows 设备上的新 `.ps1` 首次保存使用 UTF-8 BOM，让 Windows PowerShell 5.1 正确读取中文。已有文件及其另存副本保持原格式。5.1 默认重定向生成的 UTF-16 文件只能下载；需要在工作台编辑输出时，使用 `Out-File -Encoding UTF8`。

保存通过新文件替换原文件，父目录必须允许创建文件和重命名。普通权限位会保留；属主、属组、ACL 和扩展属性按新建文件的规则确定，其他硬链接仍指向旧内容。保存符号链接时写入它指向的文件。

### Markdown 预览

Markdown 源码会按编辑区宽度自动折行，文件中的实际换行不变。

`.md` 和 `.markdown` 文件可以在源码与预览间切换，预览包含尚未保存的修改，`mermaid` 代码块渲染为图表。点击相对文件链接会在文件工具中打开目标。原始 HTML 显示为文本；普通 Markdown 中的外部图片显示为链接，而图表中的外链图片会自动加载。

切到其他文件、隐藏正文或跨工作区再返回该草稿时，保留预览模式，并在正文重新可见时恢复原可见段落的位置；从终端行号或搜索结果定位时显示源码。

### HTML 预览

`.html` 和 `.htm` 默认打开源码；“预览 HTML”运行当前稿件，包括尚未保存的修改。支持内联 JavaScript、样式、SVG/data 图片及浏览器允许的外部 CDN 资源。相对资源不会读取相邻工作区文件；需要项目服务或多文件资源时，使用[访问开发服务](#访问开发服务)。

预览与工作台隔离，但文档及 CDN 脚本能读取并发送整份预览内容。模块、fetch 和字体仍受浏览器 CORS 规则限制，localStorage/sessionStorage 不可用。链接、脚本或 meta refresh 可以在框内换页，浏览器后退可能先回退框内页面；表单提交、新窗口和顶层跳转不开放。

切源码、稿件、工作区或隐藏正文后结束当前预览；正文仍可见时切换右侧工具或搜索不会重启预览。再次显示预览时重新运行，框内表单值和图表选择会重置；源码草稿和撤销历史保留。终端行号跳转会回到源码。保存写入稿件，下载读取磁盘文件，框内交互不会改写源码。

### 草稿

草稿只保存在当前页面的内存中：

- 切换文件、工具、工作区或设备时保留。“打开的文件”可找回所有设备上打开的草稿。未保存稿在文件标签和“打开的文件”中显示圆点。
- 应用内关闭文件标签时，有未保存内容会询问取消、放弃或保存后关闭；空白未命名稿可直接关闭。
- 有未保存修改时，刷新、离开或关闭页面前浏览器会提示；确认离开后草稿丢失。手机关闭应用或系统回收页面时可能不提示。
- 设备离线、设备或工作区被删除时，内容仍可查看和复制，但不能保存到原位置。
- 工作区显示渲染错误时，可用“返回设备”继续导航；整个工作台显示错误页时，内存中的草稿无法恢复。

### 保存冲突

具名文件点“保存”会直接提交。只有本次保存遇到磁盘版本冲突时，才读取当前磁盘，让你选择覆盖这一版本、查看磁盘或取消；取消会保留草稿。查看磁盘在同一窗口展开全文，可查找、选择和复制，也可加载磁盘版并放弃草稿；复杂比较可复制到外部工具处理。

覆盖只针对窗口中读取的版本。该版本又被改动时，覆盖会被拒绝，需重新核对后再决定；读取失败时不能覆盖。

保存结果未确认（例如保存中断线）时，用“核对磁盘内容”读取原目标。与上次发送内容逐字节一致便确认已保存，发送后的新增输入仍会保留；不一致时继续保留未保存状态，工作台不会自动重发。后台刷新不会确认这次保存。

### 搜索

文件搜索在工作区磁盘文件中查找正文和文件名，规则如下：

- 按字面文本匹配，区分大小写。
- “文件名”在文件的相对路径（含目录部分）中查找包含查询文本的文件，结果只有文件。
- 包含隐藏文件，不搜索 `.git`，不进入任何符号链接（指向文件或目录的都不进入）。
- `.gitignore` 只在 Git 仓库内生效，`.ignore` 和 `.rgignore` 始终生效；勾选“包含已忽略项”可搜索被这些规则排除的文件。
- 结果数量和时间有上限（见[限额](reference.md#限额)），达到时显示“结果不完整”；路径不是合法 UTF-8 的结果不显示，也标为不完整。

同一工作区内打开结果后，可返回当前搜索继续打开其他结果。修改查询文字或条件后，旧结果清空，需要重新搜索；跨工作区返回时可能需要重新填写条件并搜索。打开正文结果时，如果原位置的文字已不匹配查询，编辑器会打开文件内查找；点击“下一个”在当前内容中继续查找。

### 新建与重命名

“新建文件”直接打开未命名草稿，首次保存时填写路径，默认目录为新建时工具栏显示的目录；文件夹菜单的“新建目录”在所指目录内创建。保存前设备和 Git 看不到这个文件。首次保存、新建目录和重命名遇到已有名称时都失败，不覆盖。重命名或移动后，打开的标签跟随到新路径。工作区根目录和正在保存的文件不能重命名、移动或删除。

路径输入保留粘贴内容中的换行。新建目录、重命名、首次保存或另存时，可按 Enter 或手机键盘的完成键提交；上传、整理和冲突路径仍用对应按钮执行。

### 上传与下载

可以从工具栏或文件夹菜单选择文件，也可直接拖入“文件”工具上传。工具栏和拖放使用当前浏览目录，文件夹菜单使用所指目录；确认框显示创建上传时的设备、工作区和起始目录，可修改目标路径。拖入内容包含目录时，整次拖放不被接收。上传逐个发送文件，数据发完后仍需等待设备完成；收起对话框不会取消上传。收起后切换工作区，重开仍面对原上传目标。向另一工作区上传时，从目标工作区重新发起。下载交给浏览器的下载管理器，目录不能下载。大小上限见[限额](reference.md#限额)。

### 整理文件

- 复制目录会递归复制，符号链接复制为链接本身，硬链接复制为独立文件。
- 同一文件系统内移动是改名，跨文件系统移动先复制再删除源。
- 目标已存在时该项失败，不覆盖文件，不合并目录，见[同名处理](#同名处理)。

删除是永久删除，没有回收站。目录递归删除，包括挂载在其中的其他文件系统里的数据，挂载点可能保留。删除符号链接只删链接本身。FIFO、socket 和设备节点不能复制、移动或删除，包含它们的目录只能部分删除。

### 同名处理

上传、复制或移动的目标已存在时，点该项的“同名处理”：

- “保留两份”：使用另一个路径；执行时该路径已被占用，该项仍会失败。
- “替换”：覆盖这个文件，目录不能替换；确认后目标又被改动时，替换不执行。目标是符号链接时只替换链接，原目标文件不变。

### 操作结果与取消

每项结果为“已完成”“未完成”（未执行或确认失败，磁盘没有变化）、“部分完成”（例如目录中的部分文件已处理）或“结果未确认”（执行中失去联系，先查看磁盘再决定）。取消只停止尚未开始的部分，已完成的部分保留。未完成的项可以修改后“重试未完成项”。

### 符号链接

文件工具跟随项目用户能访问的符号链接，可以经链接浏览工作区外的目录。打开和保存作用于链接指向的文件，重命名、移动、删除和替换只作用于链接本身。

文件工具不提供跨工作区复制；其他能力边界见[范围外](../design/files.md#范围外)。

## Git

Git 工具使用设备上的 Git 和项目用户的 Git 配置，hooks、签名和凭据按设备配置生效。安装前提见[支持的系统与准备](devices.md#支持的系统与准备)。

### 仓库发现与切换

Git 工具扫描工作区目录及其所有子目录，列出找到的仓库，包括已初始化的子模块和位于工作区内的 linked worktree（标为 `worktree`）。工作区之外的仓库不会被使用：工作区如果只是某个仓库的子目录，会显示“没有发现 Git 仓库”，请把仓库根目录添加为工作区。

有多个仓库时自动选中第一个可用仓库，用仓库菜单按路径切换；菜单标记当前仓，`.` 显示为“工作区根目录”。显示“仓库扫描未完成”时点“继续扫描”，“重新发现仓库”从头扫描。读取失败或扫描未完成时，先处理错误或继续扫描再判断仓库是否缺失。不支持裸仓库。

### 状态与 diff

桌面默认上区显示变化，下区在历史／分支之间切换；两区展开时默认按60:40分配空间，可拖动中间分隔条调整高度，也可用Tab聚焦后按上下方向键调整，Home／End移到当前允许的端点。收起一处会让另一处取得剩余空间；重开或返回工作区保持调整后的比例，刷新页面恢复默认。手机用一行导航选择变化、历史或分支，一次显示一个区域。顶栏当前分支直接进入分支区；切区域或收开不会清空草稿、已选提交或已打开 diff。各区域的刷新只主动刷新该区，刷新变化不会将历史深页重置到首屏。

右侧 Git 管理变化、历史、分支和仓库操作；中间工作页展示具体 diff。可以保留多个文件或来源的 diff 来回对照，正文标题显示仓库路径，标签提示保留完整路径和父版本。勾选列表行不会切换正文。从 diff 打开源文件时，右侧仍保留 Git。暂存或取消暂存后保留当前页及其比较来源。

diff 默认使用统一视图。宽屏的布局图标表示当前状态，单击在统一和左右双列之间切换；提示文字说明当前和下一布局。统一视图按实际正文面板宽度折行，双列长行在各列内折行，源文和原行号不变；长生成行会增加纵向阅读距离。窄窗口使用统一视图，扩大窗口后恢复之前的选择。工作树、暂存和历史 diff 共用这一选择。

行内变化用较深的底色强调，双列根据未变内容对齐对应行。对齐只使用当前 patch 的上下文，重复内容可能对应不理想；计算期间或失败时仍可阅读原 diff，并显示相应状态。

diff 超过限额时只显示部分原始 patch。条目说明已知状态、重命名原路径、文件模式及二进制信息。变化行已知磁盘文件缺失时，其打开文件入口不可用；历史删除只描述所选提交。变化列表有前后页时才显示分页行；“暂存的更改”显示全仓数量，其余组显示当前页数量，当前页某组为空不表示全仓干净。路径不是合法 UTF-8 的项不能操作。

变化行的圆点表示该文件有未保存草稿。工作树比较读取设备磁盘与暂存区，暂存比较读取暂存区与 HEAD；有相关未保存草稿时，diff 会说明这一来源，不读取网页草稿。保存结果未确认的草稿也可能已写入磁盘，需回到文件中核对。

### 暂存与提交

- 暂存读取磁盘，不会保存网页草稿；所选文件有未保存草稿时，会先确认是否暂存磁盘版本。要包含网页中的输入，请先保存；保存结果未确认时先核对。
- 操作会连带改变未选中的路径时不执行，并列出这些路径和需要先做的操作。
- 取消已暂存的重命名时同时处理新旧两个路径；“只取消暂存新路径”只处理新路径。

列表刷新后会取消已变化项的勾选，并提示取消数量。

提交包含暂存区的全部内容，不限于当前页或勾选的行。状态刷新期间，以及消息为空、有未解决的冲突或没有暂存的更改时不能提交。

桌面点击“提交消息”打开编辑框，可在暂存前先写消息；手机从“提交”打开。取消后消息草稿保留，提交成功后清空已提交的消息。

### 丢弃更改

“丢弃未暂存更改”恢复为暂存区中的版本，“丢弃全部更改”恢复为 HEAD 中的版本。执行前核对每项将被恢复还是删除；列为删除的文件（例如未跟踪文件）被永久删除。核对后文件又变化时不执行，需要重新核对。

### 分支与历史

“分支”视图列出本地分支，点分支行可展开完整名称、提交 OID 与工作树路径。分支导航的“创建分支”从当前 HEAD 开始，历史详情的创建入口从该提交开始。被其他工作树检出的分支不能切换或删除。切换不强制覆盖本地修改；删除执行 `git branch -d`，未合并的分支会被拒绝；Git 拒绝时显示[结果未确认](#结果未确认)。

历史首屏在读到新的 HEAD 后自动更新；翻到后续页时保留原快照，新增提交不会打乱当前页。点上一页回到首屏，或在历史中主动刷新，会读取最新历史；主动刷新将历史列表返回首屏。已打开的提交详情、所选父提交和 diff 保持原比较来源。

历史中的文件增删行数和 diff 与同一父提交比较，合并提交可以选择父提交。二进制文件不显示行数。

### 同步与认证

手机上从“远端操作”菜单执行 Pull 和 Push。

Pull 执行 `git pull`，合并时使用默认提交消息，配置为交互式 rebase 的 pull 会失败。Push 执行 `git push`，没有强制推送。

认证无法交互，Git 不会弹出用户名或密码输入：SSH 密钥、ssh-agent 或凭据助手必须在 agent 的环境中无需输入即可使用。认证失败时，点反馈中的“终端”，在同一工作区的终端里运行相同的 Git 命令完成配置（例如让凭据助手保存凭据），再回来重试。agent 作为服务运行时见[后台运行](devices.md#后台运行)。

### 冲突与继续

仓库处于 merge、rebase、cherry-pick、revert 或 am 中时（包括在终端中开始的），顶部显示操作名称和原因，并提供“继续”“中止”和“在终端处理”：

1. 在文件工具或终端中解决冲突并保存。
2. 在 Git 中点冲突行的加号，标记已解决。
3. 没有冲突后点“继续”，使用默认的提交消息。

“中止”确认后让 Git 恢复操作前的状态，未提交的内容可能受影响。网页只能继续由普通 pick 步骤组成的 rebase；含 edit、reword、squash、fixup、exec 等步骤的 rebase 和无法识别的操作，请在终端中完成后回到网页刷新。

### 结果未确认

同一仓库一次执行一个 Git 写操作，其余排队，执行中可以“取消操作”。以下情况下工作台无法确定仓库的状态，显示“结果未确认。请刷新核查后再决定是否重试。”：

- Git 命令以失败状态退出，例如 push 被拒绝、hook 拒绝提交、存在 `index.lock`；
- 执行中失去联系；
- 操作被取消；
- 超过写操作时限（见[限额](reference.md#限额)）。

处理：展开“Git 输出”查看 Git 的原始输出，点“刷新 Git”确认分支、提交和变化，确认没有生效后再手动重试。工作台不会自动重试。

多步操作只完成一部分时显示“操作部分完成。”Stash、按行暂存等需要在终端中完成，见[范围外](../design/git.md#范围外)。

## 访问开发服务

工作台可以打开设备上监听本机端口的 HTTP 服务，包括 WebSocket（含热更新）和 SSE。链接需要工作台登录，不是公开分享。关闭页面不会停止开发服务；退出登录、登录到期或删除设备会断开已打开的连接。

### 打开端口

点击左侧导航中设备名称旁的“访问端口”，在对应设备的对话框中输入端口。左栏收起时先展开导航。候选是一次快照，可能包含非 HTTP 服务；未列出的端口也可以手工输入。

服务必须在 agent 所在的机器（或容器）中监听 `127.0.0.1`、`::1`、`0.0.0.0` 或 `::`。容器见[在容器中运行](devices.md#在容器中运行)。

终端输出中主机为 `localhost`、`127.0.0.1`、`[::1]`、`0.0.0.0` 或 `[::]` 的 `http:` 链接会转换为该设备端口的地址：桌面上点击打开，手机上长按选中完整链接后点“访问设备端口”。其他链接按原地址打开。

### 两种路径模式

| 模式       | 地址                         | 开发服务收到的路径 |
| ---------- | ---------------------------- | ------------------ |
| “普通路径” | `/proxy/DEVICE_ID/PORT/…`    | 去掉前缀           |
| “保留路径” | `/absproxy/DEVICE_ID/PORT/…` | 包含完整前缀       |

“普通路径”适合只使用相对地址的页面。页面用 `/` 开头的路径引用资源时，请求会落到工作台根路径，表现为空白页或 MIME 类型错误；这类项目改用“保留路径”，并把项目的 base 设为 `/absproxy/DEVICE_ID/PORT/`。

开发服务收到的 `Host` 是你访问工作台的地址（如 `kiteline.example.com:8443`），工作台的登录 Cookie 不会转给它。设备 ID 可以从设备页地址 `/devices/DEVICE_ID` 取得，或选“保留路径”后“复制链接”。

### 配置 Vite

Vite 项目使用“保留路径”，在 `vite.config.js` 中设置：

```js
export default {
  base: "/absproxy/DEVICE_ID/3000/",
  server: {
    port: 3000,
    strictPort: true,
    allowedHosts: ["kiteline.example.com"],
    proxy: {
      "/absproxy/DEVICE_ID/3000/api": {
        target: "http://127.0.0.1:8000",
        rewrite: (path) => path.replace("/absproxy/DEVICE_ID/3000", ""),
      },
    },
  },
};
```

- `DEVICE_ID` 换成设备 ID，`3000` 换成开发服务端口。
- `allowedHosts` 列出访问工作台用的每个域名，不带端口；用 IP 或 `localhost` 访问时不需要。缺少时 Vite 返回 403 和 `Blocked request`。
- `server.proxy` 的键必须带 base 前缀，否则请求得到的是 `index.html`。上例中后端收到去掉前缀的 `/api/…`。
- Vite 处理的 HTML 资源自动加上 base，热更新默认经同一地址连接，不需要另外配置。

应用代码自己拼接的地址从 base 构造，路由器的 base 也用同一前缀：

```js
const base = new URL(import.meta.env.BASE_URL, location.origin);
fetch(new URL("api/status", base));
const socketUrl = new URL("socket", base);
socketUrl.protocol = location.protocol === "https:" ? "wss:" : "ws:";
const socket = new WebSocket(socketUrl);
```

### 常见错误

- 跳转到登录页：这个浏览器未登录或登录已到期，登录后自动回到原地址。
- 502：端口上没有服务、服务只监听其他地址或不是 HTTP 服务。
- 503：设备离线。426：agent 与 server 版本不一致，见[升级 agent](devices.md#升级-agent)。404：设备 ID 不存在。
- 504、429：连接超时或设备连接数已满，稍后重试。
- 空白页、MIME 类型错误：改用“保留路径”并配置 base。

这些错误页由工作台生成，是英文的；开发服务自己返回的错误原样显示。

### 安全提示

开发页面与工作台同源（协议、域名、端口相同）。页面中的脚本可以像你一样调用工作台接口，包括在任何设备上执行命令、改写文件；所有项目和端口的页面共用 `Path=/` 的 Cookie、localStorage 和 Service Worker，可能互相覆盖，页面返回的 `Clear-Site-Data` 能清掉工作台登录。只打开你信任的项目，不要经这里访问来源不明的服务。机制见[安全边界](../design/http-access.md#安全边界)。
